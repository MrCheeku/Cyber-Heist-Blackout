# Contributing

Thanks for helping improve Cyber Heist // Blackout.

## Before you contribute

- Keep gameplay simulations fictional and safe.
- Do not add real credentials, private keys, tokens, or unauthorized targets.
- Prefer focused pull requests with a clear purpose.
- Preserve the existing cyberpunk Compose visual language.

## Development

Open the project in Android Studio, sync Gradle, then run the test/build tasks available in your environment.

## Pull requests

Explain what changed, why it changed, and how you tested it. Screenshots or short recordings are welcome for UI changes.
