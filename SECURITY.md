# Security Policy

## Safe use

Cyber Heist // Blackout is an educational cybersecurity simulation. Its targets, credentials, network addresses, flags, terminals, and exploit scenarios are fictional game content.

Do not use the app to access, scan, exploit, or interfere with systems without explicit authorization.

## Secrets

Never commit API keys, access tokens, private keys, certificates, `.env` files, Android keystores (`.jks`, `.keystore`), passwords, or exported credentials.

Use local environment variables for release signing and `GEMINI_API_KEY`.

## Reporting

If you discover a security issue in the repository itself, report it privately through GitHub rather than publishing credentials or exploit material in an issue.
